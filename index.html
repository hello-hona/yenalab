Features

주요 기능

현재 앱에 실제로 들어가 있는 기능 기준으로 정리했습니다.

✍️

손글씨 인식 채점

화면에 직접 손으로 답을 쓰면 Google ML Kit이 숫자와 기호를 인식해 자동 채점합니다.

📚

전 학년 교육과정

1~6학년, 1학기·2학기·종합평가 구조로 단원을 탐색하고 문제를 풀 수 있습니다.

🤯

AI 문장제

매우 어려워요 난이도에서는 Gemini가 아이 이름을 넣은 창의적인 문장제 문제를 생성합니다.

💡

3단계 힌트 시스템

무료 힌트 → 광고 시청 심화 힌트 → 리워드 광고 후 풀이과정 + 정답 공개까지 단계별로 제공합니다.

😮

오답 피드백 연출

오답 시 문제 카드가 흔들리고 배경이 분홍으로 바뀌며, 정답 시 도장 스탬프와 초록 배경으로 전환됩니다.

📕

오답노트

틀린 문제를 자동 저장하고, 학년별로 다시 풀면서 정답 처리 시 기록을 정리할 수 있습니다.

📊

학습 기록

세션 결과를 로컬 DB에 저장하고 달력 기반으로 학습 이력을 확인할 수 있습니다.

🖍️

젤리와 펜 상점

높은 정답률로 젤리를 얻고, 여러 색 펜을 구매해 필기 캔버스에 바로 적용할 수 있습니다.

⚙️

설정

닉네임 변경(젤리 50개), 개인정보처리방침 확인, 고객센터 문의, 회원 탈퇴를 한 화면에서 처리할 수 있습니다.

Privacy Policy

개인정보 처리방침

현재 앱의 로그인·동기화 구조를 반영한 최신 안내입니다.

1. 개요

예나랩(yenalab)이 제공하는 초등 수학 퀴즈 앱은 아동 학습을 돕는 서비스입니다. 당사는 아동의 개인정보 보호를 중요하게 여기며, 관련 법령과 플랫폼 정책을 준수하기 위해 필요한 범위 내에서만 정보를 처리합니다.

2. 수집하는 정보

본 앱은 서비스 제공과 계정 복구를 위해 다음 정보를 수집하거나 저장합니다.

  • 사용자가 입력한 아이디
  • 보호자 이메일 주소
  • 사용자가 입력한 닉네임
  • 학년 정보
  • 학습 기록, 퀴즈 결과, 오답노트, 젤리 수, 구매한 펜 목록
  • Firebase 인증에 의해 생성되는 계정 식별자(UID)

다음 정보는 수집하지 않습니다.

  • 연락처, 기기 주소록, 위치 정보
  • 사진첩, 마이크, 카메라 기반 개인 콘텐츠
  • 행동 기반 광고를 위한 관심사 프로파일링 정보

3. 이용 목적

  • 회원가입, 로그인, 비밀번호 찾기 지원
  • 재설치 후 학습 데이터 복구
  • 닉네임 기반 AI 문제 개인화
  • 오답노트, 학습 기록, 젤리 및 펜 구매 상태 저장

4. 광고 및 제3자 서비스

  • Firebase Authentication / Cloud Firestore: 계정 인증 및 학습 데이터 동기화
  • Google AdMob: 광고 제공
  • Google ML Kit: 손글씨 인식
  • Google Gemini API: 매우 어려워요 난이도의 AI 문제 생성

광고와 외부 서비스는 각 서비스 제공자의 정책에 따라 운영될 수 있습니다.

5. 데이터 보관 및 삭제

학습 기록과 계정 정보는 서비스 운영과 복구를 위해 Firebase 및 기기 로컬 저장소에 보관됩니다. 앱 내 회원 탈퇴 기능을 통해 계정을 삭제할 수 있으며, 추가 삭제 요청은 지원 이메일로 접수할 수 있습니다.

6. 보호자 권리

보호자는 자녀 계정과 관련하여 데이터 삭제나 처리 문의를 요청할 수 있습니다. 문의는 아래 이메일로 접수해 주세요.
