셈한걸음 개인정보처리방침

회원가입, 학습 기록 동기화, 광고 보상, AI 문제 생성 구조를 반영한 앱 전용 정책입니다.

1. 개요

예나랩이 제공하는 셈한걸음은 초등학생의 수학 학습을 돕는 서비스입니다. 당사는 아동과 보호자의 개인정보를 중요하게 여기며, 서비스 제공에 필요한 범위 안에서만 정보를 처리합니다.

2. 수집하거나 저장하는 정보

  • 사용자 아이디
  • 보호자 이메일 주소
  • 닉네임, 학년 정보
  • 학습 기록, 퀴즈 결과, 오답노트, 젤리 수, 구매한 항목
  • Firebase 인증 식별자(UID)
  • 기기 로컬 설정 정보와 광고 보상 처리에 필요한 상태값

3. 이용 목적

  • 회원가입, 로그인, 비밀번호 재설정 지원
  • 재설치 후 학습 데이터 복구
  • AI 문제 개인화와 기능 제공
  • 광고 보상 처리, 서비스 안정성 유지, 부정 사용 방지

4. 제3자 서비스

  • Firebase Authentication / Cloud Firestore / Cloud Functions
  • Firebase App Check
  • Google AdMob
  • Google ML Kit
  • Firebase AI / Gemini

각 서비스는 계정 인증, 데이터 동기화, 무결성 검증, 광고 제공, 손글씨 인식, AI 기능 제공을 위해 필요한 범위의 정보를 처리할 수 있습니다.

5. 보관 및 삭제

학습 데이터와 계정 정보는 서비스 운영과 복구를 위해 Firebase와 기기 로컬 저장소에 보관됩니다. 이용자는 앱 내 회원 탈퇴 기능 또는 지원 이메일을 통해 삭제를 요청할 수 있습니다.

6. 보호자 권리와 문의

보호자는 자녀 계정에 대해 데이터 삭제, 처리 문의, 정책 문의를 요청할 수 있습니다. 문의는 official@yenalab.com 으로 접수해 주세요.
